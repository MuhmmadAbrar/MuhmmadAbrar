# Hi, I'm Abrar 👋

Software engineer working on AI agent orchestration, MCP tools, and building intelligent systems. Currently exploring how to make AI agents actually useful in production environments.

## What I'm working on

- **📄 Text2Report - A Smart Report Generator**  
Building a text-to-PDF report generation tool that converts any serializable input (strings, JSON, dicts, tuples) into polished reports with charts and visualizations. Uses Mermaid and Chart.js for graphics, with heavy customization options built into the codebase. Not your typical LLM wrapper - this is about giving developers real control over output formatting.

## What I'm proud of

- **🏠 Intelligence of Things** (Final Year Project)  
Built an IoT control system that uses spatial awareness to understand context. Instead of saying "turn on living room fan 1", you just say "turn on the fan" and it figures out which one based on your location. Combines spatial reasoning with IoT automation to make smart homes actually smart.

## Currently Learning

Diving deep into **MCP (Model Context Protocol)** tools. Interested in how we can build better AI pipelines and agent orchestration systems that actually scale.
